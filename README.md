# MineColonies — Colony Builder Mod

[![Download Latest](https://img.shields.io/github/v/release/polygonrhymeshrink/minecolonies-city-builder-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/polygonrhymeshrink/minecolonies-city-builder-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Build and manage a thriving NPC colony with workers, guards, builders, and a full medieval town.

## Features

- Assign citizen workers: farmers, miners, cooks, guards
- Automated builder NPC constructs buildings for you
- Research tree unlocking advanced colony features
- Supply ships and camps to start your colony fast
- Multiplayer support with shared colony management

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
